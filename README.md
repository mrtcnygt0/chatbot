# AI Chat - Production-Ready ChatGPT Clone

A complete, production-ready ChatGPT-like web application with modern UI, secure authentication, MySQL backend, token quota system, admin panel, and OpenAI API integration (gpt-4o-mini only).

## 🌟 Features

### User Features
- **ChatGPT-Style UI** - Modern, responsive interface with sidebar and conversation history
- **Real-time Chat** - Send messages and receive AI responses
- **Conversation Management** - Create, rename, and delete conversations
- **Token Quota System** - Track daily/monthly usage limits
- **Secure Authentication** - Login and registration with password hashing
- **Markdown Support** - Format messages with code blocks and styling

### Admin Features
- **User Management** - View, edit, and manage user accounts
- **Quota Control** - Set custom token limits for each user
- **Usage Dashboard** - Track costs, requests, and daily usage
- **API Kill Switch** - Emergency disable API access
- **Cost Tracking** - Monitor spending per user and total

### Technical Features
- **PHP 8.1+ Backend** - Modern PHP with clean MVC architecture
- **MySQL Database** - Structured data storage with migrations
- **OpenAI Integration** - gpt-4o-mini API with error handling
- **Security** - CSRF protection, rate limiting, SQL injection prevention
- **Budget Control** - Strict cost tracking and quota enforcement
- **Responsive Design** - Works on desktop, tablet, and mobile

## 📋 Requirements

- PHP 8.1 or higher
- MySQL 8.0 or higher
- PDO PHP Extension
- cURL PHP Extension
- OpenAI API Key

## 🚀 Installation

1. **Clone or download this repository**
   ```bash
   git clone https://github.com/mrtcnygt0/chatbot.git
   cd chatbot
   ```

2. **Set up your web server**
   - Point your document root to the `public` folder
   - Ensure `.htaccess` is enabled (Apache)
   - Or configure your web server accordingly (Nginx)

3. **Run the installer**
   - Navigate to `http://your-domain.com/install.php`
   - Fill in the form with:
     - Database connection details
     - Admin account credentials
     - OpenAI API key
   - Click "Install AI Chat"

4. **Complete!**
   - After installation, you'll be redirected to the login page
   - Login with your admin credentials
   - Start chatting or manage users from the admin panel

## 🔧 Configuration

After installation, you can modify settings in `config/config.php`:

- **Database** - Connection details
- **OpenAI** - API key, model, temperature, max tokens
- **Security** - Session lifetime, login attempts, lockout duration
- **Rate Limiting** - Requests per minute/hour
- **Budget** - Default quotas, token costs

## 💰 Cost Management

The application uses gpt-4o-mini with the following pricing (as of 2024):
- Input: $0.15 per 1M tokens
- Output: $0.60 per 1M tokens

Default user limits:
- 100,000 total tokens
- 10,000 tokens per day
- 100,000 tokens per month

Admins can customize these limits per user from the admin panel.

## 🛠 Development

### Adding New Features

1. **Models** - Add to `app/models/`
2. **Controllers** - Add to `app/controllers/`
3. **Services** - Add to `app/services/`
4. **API Endpoints** - Add to `public/api/` or `admin/api/`
5. **Frontend** - Update HTML, CSS in `public/`, JS in `public/assets/js/`

### Database Changes

To modify the database schema:
1. Edit `database/migrate.sql`
2. Run migrations manually or via installer

## 📝 API Endpoints

### User APIs
- `POST /api/login.php` - User login
- `POST /api/register.php` - User registration
- `POST /api/logout.php` - User logout
- `GET /api/conversations.php` - Get conversations
- `POST /api/conversations.php` - Create/rename/delete conversation
- `GET /api/messages.php` - Get conversation messages
- `POST /api/chat.php` - Send message
- `GET /api/quota.php` - Get user quota

### Admin APIs
- `GET /admin/api/dashboard.php` - Dashboard statistics
- `GET /admin/api/users.php` - Get all users
- `GET /admin/api/user-details.php` - Get user details
- `POST /admin/api/update-quota.php` - Update user quota
- `POST /admin/api/toggle-status.php` - Enable/disable user
- `POST /admin/api/delete-user.php` - Delete user
- `POST /admin/api/toggle-api.php` - Enable/disable API

## 🐛 Troubleshooting

### Installation Issues
- Ensure PHP version is 8.1+
- Check MySQL credentials
- Verify PDO extension is enabled
- Check file permissions

### Runtime Issues
- Check `error_log` for PHP errors
- Verify OpenAI API key is valid
- Check database connection
- Ensure `.htaccess` is working

### API Issues
- Verify OpenAI API key
- Check quota limits
- Review API logs in admin panel
- Check rate limiting settings
